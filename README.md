# Frontend AC Learning Journey

This repository contains the complete learning path covered across the Frontend AC batches.

## Overview

- Batch 01: HTML, CSS, layouts, and responsive design
- Batch 02: JavaScript fundamentals and DOM interaction
- Batch 03: Modern JavaScript, APIs, and async programming
- Batch 04: React basics and frontend project building

## Batch-wise learning summary

### Batch 01
- HTML structure and semantic tags
- CSS fundamentals and layout design
- Box model, Flexbox, and Grid
- Responsive design and media queries
- Form styling and web page structure

### Batch 02
- JavaScript basics
- Variables, arrays, objects, and functions
- Conditions, loops, and scope
- DOM selection, manipulation, and events
- Interactive form handling

### Batch 03
- ES6+ features
- Arrow functions, destructuring, spread/rest
- Async JavaScript and promises
- Fetch API and JSON handling
- Local storage and API-based frontend projects

### Batch 04
- React fundamentals
- JSX, components, props, and state
- Event handling and forms
- Conditional rendering and lists
- Hooks and build patterns
