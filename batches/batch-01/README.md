# Batch 01

## Topics Covered

- Introduction to web development
- HTML structure and semantic tags
- Forms and input elements
- CSS basics and syntax
- Selectors, properties, and values
- Box model, padding, margin, and border
- Display, positioning, and layout concepts
- Flexbox and Grid
- Typography and spacing
- Responsive design and media queries
- Project structure and UI building

## Outcome

Students learn how to build clean and responsive web pages using HTML and CSS.
